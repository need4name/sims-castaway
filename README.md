# Castaway Cove

A cosy desert-island life game for phones, in the spirit of the old handheld castaway life sims. Everything in it (art, story, characters) is original.

Wake on the beach after a shipwreck. Keep your Hunger, Energy, Hygiene, Fun and Comfort up, gather from palms, jungle trees, rocks and the sea, craft tools, build a camp, befriend Pip the monkey, find buried treasure, light the signal fire and sail home on a raft.

**Play:** open `index.html` in a phone browser (works offline once loaded; progress saves on the device). Add it to the home screen for a full-screen app feel.

- `castaway.html` is the game source (published as a claude.ai Artifact).
- `index.html` is the standalone build, made by `./build.sh`. Enable GitHub Pages on this repo to host it.
